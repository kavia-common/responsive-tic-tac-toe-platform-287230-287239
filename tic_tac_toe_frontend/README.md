# Tic Tac Toe (Ocean Professional)

A responsive, modern Tic Tac Toe game built with React and no backend.

## Play
- Start the app with `npm start` and open http://localhost:3000
- Header controls:
  - Mode switch: PvP (local 2-player) or Vs CPU
  - Restart: reset the game
- Move History: jump to any move

## Accessibility
- Cells are focusable and support Enter/Space to place a mark
- Arrow keys move focus between cells
- Live status announces turns, wins, and draws
